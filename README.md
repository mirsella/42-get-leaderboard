# 42 Get Leaderboard

Small Rust CLI that fetches 42 Intra users and prints a leaderboard sorted by `42cursus` level.

The current code is hardcoded to campus `1` and the `2022` July/August/September pool.

## Run

```bash
export TOKEN="your-42-intra-bearer-token"
cargo run
```

## Build

```bash
cargo build --release
```
